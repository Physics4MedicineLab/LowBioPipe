# NOTES ON FILTERING MODES
#
# By default, filter_taxa.py filters only EXACT taxids listed above.
#
# To also filter ancestor/descendant taxa, use:
#   --include-ancestors    : Also remove ancestors, up to --ancestors-max-rank
#                            (default genus; root and 'cellular organisms' never)
#   --include-descendants  : Also remove child taxa (strains, subspecies)
#
# In the pipeline these are --filter_include_ancestors,
# --filter_ancestors_max_rank and --filter_include_descendants.
#
# Example:
#   filter_taxa.py --taxdump taxdump \
#                  --exclude contaminants.txt \
#                  --indir kraken2_output \
#                  --outdir filtered_reads \
#                  --include-descendants
